SECTION A : ANTÉCÉDENTS MÉDICAUX
Question 1 : Antécédents de diabète type 2, hypertension, maladies cardiovasculaires
RÉPONSE : OUI
Adaptations nutritionnelles :
•	Réduire drastiquement le sel : maximum 5g/jour
•	Éviter les cubes Maggi, sel d'assaisonnement
•	Privilégier les épices naturales : gingembre, ail, piment, oignon, citronnelle
•	Limiter les aliments transformés
RÉPONSE : NON
Adaptations :
•	Pas de restrictions particulières au-delà du contrôle glycémique
•	Possibilité d'utiliser modérément les épices salées traditionnelles (avec parcimonie)
•	Focus sur l'équilibre glycémique
Conseils :
•	Maintenir une alimentation équilibrée préventive
•	Contrôle glycémique régulier
•	Activité physique régulière
Question 2 : Si oui, lequel ?
DIABÈTE DE TYPE 2
Adaptations ultra-spécifiques :
•	Index glycémique bas prioritaire
•	Jamais de sucres rapides
•	Contrôle strict des portions de glucides
•	3 repas réguliers + 2 collations pour stabilité glycémique
Repas spécial diabète :
Petit-déjeuner IG bas :
•	Bouillie de mil non sucrée + œufs + avocat + cannelle (aide à réguler glycémie)
•	Akassa + haricots riches en fibres + légumes verts
Déjeuner contrôlé :
•	Fonio (IG bas) + sauce feuilles + poisson gras (oméga-3) + légumes
•	Quinoa local si disponible + sauce tomate maison + poulet
Dîner léger diabète :
•	Légumes verts en grande quantité + protéines + petite portion de tubercule
•	Soupe épaisse de légumes + poisson + gari minimal
Collations anti-pic glycémique :
•	10 arachides + 1 petite pomme verte
•	Concombre + tomates + œuf dur

RÉPONSE : OUI
Adaptations générales :
•	Coordination horaires repas-médicaments essentielle

•	Noter les horaires de prise de médicaments
•	Adapter les horaires des repas en conséquence
•	Certains aliments peuvent interagir (exemple : pamplemousse avec certaines statines)
•	Hydratation accrue si diurétiques
Planning type avec médication :
•	7h00 : Médicaments du matin + petit-déjeuner complet
•	12h30 : Déjeuner

•	19h30 : Dîner
•	21h00 : Médicaments du soir si nécessaires

•	Gestion par l'alimentation et mode de vie prioritaire

Question 4 : Si oui, lesquels ? (Réponse ouverte)
Adaptations selon médicaments courants :
Exemples de réponses et adaptations :
1.	"Metformine 850mg matin et soir" 
o	Prendre avec repas pour éviter troubles digestifs
o	Augmenter fibres pour compenser effets secondaires
o	Petit-déjeuner : Bouillie riche en fibres + œufs
o	Dîner : Légumes abondants + protéines
2.	"Amlodipine 5mg le matin" 
o	Prendre à jeun ou avec petit-déjeuner

o	Boire beaucoup d'eau
3.	"Atorvastatine 20mg le soir" 
o	Prendre au dîner
o	Éviter pamplemousse
o	Augmenter fibres solubles (gombo, aubergine)

4.	"Gliclazide 30mg avant déjeuner" 
o	Déjeuner dans les 30min après prise
o	Déjeuner consistant obligatoire
o	Surveiller hypoglycémies

Conseils généraux médicaments :
•	Jamais sauter de repas avec antidiabétiques
•	Toujours avoir collation d'urgence (fruits secs)
•	Noter effets secondaires alimentaires
•	Consultation pharmacien pour interactions
Question 5 : Prenez-vous actuellement l'un des types de médicaments suivants ?
OPTION : Médicaments pour baisser la glycémie (metformine, glimepiride…)
Adaptations critiques :
•	Régularité absolue des repas - jamais sauter
•	Collations préventives hypoglycémie
•	Glucides à chaque repas (selon répartition niveau activité)
•	Surveillance glycémie avant/après repas
Repas adaptés metformine :
Petit-déjeuner (avec metformine) :
•	Bouillie de mil riche en fibres - 200g
•	Œufs brouillés - 2
•	Avocat - ⅓ unité
•	Pain complet - 1 tranche
•	Prendre metformine pendant le repas
Déjeuner (avec metformine) :
•	Riz complet - portion selon activité
•	Sauce feuilles riches en fibres - 150g
•	Poisson grillé - 120g
•	Légumes variés
•	Prendre metformine pendant le repas
Collations obligatoires :
•	10h : Fruits + quelques arachides
•	16h : Gari + sardines (si metformine cause fatigue)
Conseils metformine :
•	Prendre TOUJOURS avec nourriture
•	Augmenter fibres (réduit effets secondaires digestifs)
•	Boire beaucoup d'eau
•	Surveiller signes hypoglycémie (tremblements, sueurs)
Repas adaptés sulfamides (glimepiride, gliclazide) :
ATTENTION : Risque hypoglycémie plus élevé
Petit-déjeuner sécuritaire :
•	Bouillie de maïs - 200g
•	Œufs - 2-3
•	Avocat - ½
•	Pain complet - 1-2 tranches
•	Banane plantain bouillie - 80g
•	Glucides suffisants pour éviter hypoglycémie
Déjeuner post-sulfamide :
•	Féculent complet généreux - selon activité
•	Protéines abondantes
•	Légumes
•	Jamais sauter ce repas
Collations OBLIGATOIRES :
•	10h : Substantielle (plantain + arachides)
•	16h : Fruits + protéines
Kit anti-hypoglycémie toujours disponible :
•	Quelques morceaux de sucre
•	Jus de fruits naturel
•	Biscuits secs complets
Signes d'alerte hypoglycémie :
•	Tremblements
•	Sueurs froides
•	Faim intense
•	Confusion
•	→ Prendre immédiatement 15g glucides rapides

OPTION : Médicaments pour perdre du poids (orlistat, liraglutide…)
ORLISTAT (Xenical) :
Mécanisme : Bloque absorption 25% graisses alimentaires
Adaptations critiques :
•	Réduire graisses à 15g max par repas
•	Augmenter fibres
•	Suppléments vitamines liposolubles (A, D, E, K) au coucher
•	Risque diarrhées grasses si trop de lipides
Repas adaptés orlistat :
Petit-déjeuner faible gras :
•	Bouillie de maïs écrémée - 200g
•	Blancs d'œufs - 3
•	Pain complet - 1 tranche
•	Fruits
•	Maximum 5g lipides
Déjeuner faible gras :
•	Riz complet - portion normale
•	Sauce tomate maigre (sans huile/arachide)
•	Poulet sans peau grillé - 120g
•	Légumes vapeur abondants
•	Maximum 10g lipides
Dîner faible gras :
•	Fonio
•	Soupe claire de légumes
•	Poisson maigre grillé sans huile
•	Maximum 10g lipides
Aliments à éviter absolument :
•	Sauces d'arachide
•	Sauce graine
•	Fritures
•	Avocat (limiter à petites portions)
•	Huiles en cuisson
•	Viandes grasses
Cuissons recommandées :
•	Vapeur
•	Grillé sans matière grasse
•	Bouilli
•	Wok avec spray minimal
LIRAGLUTIDE (Victoza, Saxenda) / GLP-1 :
Mécanisme : Réduit appétit, ralentit vidange gastrique
Adaptations :
•	Portions plus petites
•	Repas fréquents (5-6 par jour)
•	Aliments bien tolérés (éviter trop gras, trop épicé)
•	Hydratation accrue
•	Gérer nausées fréquentes
Repas adaptés GLP-1 :
Petit-déjeuner léger et fractionné :
•	Petite bouillie - 150g
•	1 œuf
•	Quelques fruits
•	Portions réduites car satiété rapide
Collation matinale :
•	Crackers complets + sardines
Déjeuner modéré :
•	Demi-portion habituelle
•	Riche en protéines (coupe-faim naturel)
•	Légumes
•	Féculents modérés
Collation après-midi :
•	Fruits + yaourt nature
Dîner très léger :
•	Soupe de légumes
•	Petit morceau poisson
•	Pas de féculents lourds
Gestion nausées :
•	Gingembre frais (infusion)
•	Citron
•	Repas tièdes (pas chauds)
•	Éviter odeurs fortes
•	Manger lentement
Conseils :
•	Manger même sans faim (glycémie)
•	Privilégier qualité sur quantité
•	Protéines à chaque prise
•	Boire entre (pas pendant) repas
OPTION : Médicaments pour la tension artérielle (IEC, ARA2, bêta-bloquants…)
IEC (Inhibiteurs Enzyme Conversion - ex: Ramipril, Enalapril) :
Adaptations :
•	Surveiller potassium (IEC augmentent potassium)
•	Ne PAS supplémenter potassium
•	Modérer aliments très riches en potassium si excès
•	Réduction sel stricte
Repas adaptés IEC :
Petit-déjeuner :
•	Bouillie de maïs sans sel
•	Œufs
•	Pain complet sans sel
•	Fruits modérés en potassium
•	Éviter excès banane plantain
Déjeuner :
•	Riz complet
•	Sauce sans sel, épices naturelles
•	Poisson ou poulet
•	Légumes variés (modérer épinards si potassium élevé)
Dîner :
•	Fonio
•	Légumes
•	Protéines
•	Sans sel
Surveillance : Taux potassium sanguin régulier
ARA2 (Antagonistes Récepteurs Angiotensine - ex: Losartan, Valsartan) :
Adaptations similaires aux IEC :
•	Surveiller potassium
•	Zéro sel ajouté
•	Hydratation suffisante
Conseil spécifique : Prendre toujours à la même heure (régularité)
BÊTA-BLOQUANTS (ex: Aténolol, Bisoprolol) :
Effets secondaires potentiels :
•	Fatigue
•	Ralentissement métabolisme
•	Possible gain de poids
•	Masquent symptômes hypoglycémie
Adaptations nutritionnelles :
•	Portions contrôlées (métabolisme ralenti)
•	Aliments énergisants naturels
•	Vigilance hypoglycémie si diabète
Repas adaptés bêta-bloquants :
Petit-déjeuner énergisant :
•	Bouillie de mil - 200g
•	Œufs - 2
•	Avocat - ¼
•	Thé vert (caféine modérée) ou infusion gingembre
•	Fruits vitamine C
Déjeuner équilibré :
•	Portions selon activité mais contrôlées
•	Protéines maigres
•	Glucides complexes
•	Légumes colorés (antioxydants)
Collations anti-fatigue :
•	Fruits secs + noix (énergie durable)
•	Infusions tonifiantes (gingembre, citronnelle)
Conseils bêta-bloquants :
•	Activité physique douce régulière (malgré fatigue)
•	Éviter stimulants excessifs
•	Sommeil suffisant
•	Si diabète : surveiller glycémie plus souvent (symptômes masqués)
DIURÉTIQUES (ex: Furosémide, Hydrochlorothiazide) :
Effets : Éliminent eau + potassium/magnésium
Adaptations critiques :
•	Compenser pertes potassium
•	Compenser pertes magnésium
•	Hydratation accrue
•	Surveiller crampes (signe carence)
Repas adaptés diurétiques :
Petit-déjeuner riche potassium/magnésium :
•	Bouillie de mil (magnésium)
•	Banane plantain bouillie (potassium)
•	Œufs
•	Orange fraîche (potassium)
Déjeuner :
•	Patate douce (potassium)
•	Épinards/feuilles vertes (magnésium, potassium)
•	Poisson
•	Haricots (magnésium)
Dîner :
•	Igname (potassium)
•	Sauce feuilles d'amarante (potassium, magnésium)
•	Sardines (magnésium)
•	Légumes verts
Collations riches minéraux :
•	Papaye (potassium)
•	Noix de cajou (magnésium)
•	Banane plantain
•	Avocat (potassium, magnésium)
Hydratation :
•	2.5-3L eau/jour
•	Infusions
•	Eau de coco naturelle (électrolytes)
Signes de carence à surveiller :
•	Crampes musculaires → manque potassium/magnésium
•	Fatigue intense
•	Battements cardiaques irréguliers
•	→ Consulter rapidement
OPTION : Médicaments pour le cholestérol (statines)
STATINES (Atorvastatine, Simvastatine, Rosuvastatine) :
Adaptations nutritionnelles :
•	Fibres solubles maximisées (réduisent cholestérol)
•	Oméga-3 augmentés
•	Graisses saturées réduites
•	ÉVITER PAMPLEMOUSSE (interaction dangereuse)
•	Possiblement CoQ10 en supplément (statines le réduisent)
Repas anti-cholestérol béninois :
Petit-déjeuner fibres solubles :
•	Bouillie d'avoine ou mil - 200g
•	Graines de lin moulues - 1 cuillère
•	Œufs oméga-3 (si poules nourries graines)
•	Pomme ou orange (fibres pectine)
•	Pas de pamplemousse
Déjeuner cardio-protecteur :
•	Riz complet (fibres)
•	Sauce gombo (fibres solubles excellentes)
•	Sardines ou maquereau frais (oméga-3)
•	Haricots rouges (fibres)
•	Aubergine (réduit cholestérol)
•	Ail (réduit cholestérol)
Dîner :
•	Fonio (fibres)
•	Sauce aubergine + gombo combinés
•	Poisson gras grillé
•	Légumes verts abondants
Collations anti-cholestérol :
•	Noix de cajou (15g) - stérols végétaux
•	Pomme + cannelle
•	Carotte crue (fibres pectine)
Aliments STARS anti-cholestérol béninois :
1.	Gombo - fibres solubles puissantes
2.	Aubergine - prouvée réduire LDL
3.	Haricots rouges - fibres + protéines
4.	Sardines/maquereau - oméga-3
5.	Ail - consommé cru de préférence
6.	Feuilles vertes - antioxydants
7.	Avocat - graisses mono-insaturées (modération)
8.	Noix locales - stérols végétaux
Aliments à ÉVITER :
•	Pamplemousse (interaction statines)
•	Viandes grasses
•	Fritures
•	Huile de palme excessive
•	Peau de volaille
•	Abats
Cuissons recommandées :
•	Grillé
•	Vapeur
•	Bouilli
•	Mijot sans graisse
Conseils statines :
•	Prendre le soir (cholestérol se synthétise la nuit)
•	Dîner normal (avec nourriture)
•	Douleurs musculaires → signaler médecin
•	Bilan lipidique régulier
OPTION : Aucun de ces médicaments
Adaptations :
•	Gestion nutritionnelle stricte cruciale
•	Prévention aggravation par alimentation
•	Discipline accrue nécessaire
•	Surveillance marqueurs santé régulière
Conseils :
•	Alimentation = médicament principal
•	Respecter strictement répartitions macronutriments
•	Activité physique non négociable
•	Contrôles médicaux fréquents
•	Objectif : éviter médication future
Focus prévention :
•	Perte de poids progressive (0.5-1kg/semaine)
•	Glycémie à jeun < 1.26 g/L
•	HbA1c < 7%
•	Tension < 130/80 mmHg
•	Cholestérol LDL < 1g/L
SECTION B : HABITUDES ALIMENTAIRES
Question 1 : Pouvez-vous décrire une journée typique de vos repas et collations ?
EXEMPLE RÉPONSE 1 : "Je mange souvent pâte et sauce graine le midi, parfois je saute le petit-déjeuner"
Problèmes identifiés :
•	Petit-déjeuner sauté (mauvais pour diabète)
•	Sauce graine très grasse (lipides élevés)
•	Pas de variété
•	Probablement déséquilibre macronutriments
Adaptations et conseils :
JAMAIS sauter le petit-déjeuner (diabète) :
•	Métabolisme ralenti
•	Hypoglycémie matinale
•	Pic glycémique au déjeuner compensatoire
•	Stockage graisse accru
Petit-déjeuner OBLIGATOIRE à introduire :
Semaine 1-2 (habituation) :
•	Léger : 1 fruit + quelques arachides + infusion
•	OU : Bouillie légère 150g + 1 œuf
Semaine 3-4 :
•	Petit-déjeuner complet selon niveau activité
•	Bouillie + œufs + légumes + fruit
Remplacer sauce graine quotidienne :
Alternatives sauces béninoises plus légères :
1.	Sauce tomate maison (tomates fraîches, oignon, ail, piment)
2.	Sauce feuilles d'amarante (peu d'huile)
3.	Sauce aubergine (aubergines, tomates, épices)
4.	Sauce gombo (fibres, peu gras)
5.	Sauce feuilles de baobab
Sauce graine modifiée (1-2x/semaine max) :
•	Réduire quantité pâte d'arachide de 50%
•	Ajouter légumes (aubergines, gombo)
•	Portion contrôlée : 80ml max
•	Avec protéines maigres
Planning type réorganisé :
•	7h : Petit-déjeuner complet
•	12h30 : Déjeuner varié (rotation sauces)
•	16h : Collation
•	19h30 : Dîner léger
EXEMPLE RÉPONSE 2 : "Gari le matin, riz blanc midi et soir, pas de légumes"
Problèmes identifiés :
•	Glucides raffinés excessifs (gari, riz blanc)
•	Zéro légumes (carences vitamines, fibres)
•	Index glycémique très élevé
•	Monotonie
Adaptations urgentes :
Remplacer glucides raffinés :
•	Gari → Bouillie de maïs/mil OU akassa
•	Riz blanc → Riz complet OU fonio OU mix riz-légumineuses
Introduire légumes PROGRESSIVEMENT :
Semaine 1 :
•	Ajouter tomates et oignons crus aux repas
•	Concombre en salade
•	Objectif : s'habituer au goût
Semaine 2-3 :
•	Légumes cuits simples : haricots verts bouillis, carottes
•	Sauce tomate avec légumes mixés
•	Objectif : 1 portion légumes/repas
Semaine 4+ :
•	Légumes variés à chaque repas
•	Sauces de feuilles
•	Légumes grillés
•	Objectif : 2-3 portions légumes/repas
Repas réorganisés :
Petit-déjeuner :
•	Bouillie de mil + œufs + tomates fraîches + avocat
•	Au lieu de : gari seul
Déjeuner :
•	Riz complet OU fonio
•	Sauce feuilles avec légumes
•	Poisson/poulet
•	Salade crudités
•	Au lieu de : riz blanc sauce graine
Dîner :
•	Légumes vapeur ABONDANTS (assiette pleine)
•	Protéines grillées
•	Petit tubercule complet
•	Au lieu de : riz blanc uniquement
Bénéfices attendus :
•	Glycémie stabilisée
•	Satiété augmentée
•	Transit amélioré
•	Perte poids facilitée
•	Vitamines/minéraux augmentés
EXEMPLE RÉPONSE 3 : "Je mange beaucoup le soir car je rentre tard du travail, peu dans la journée"
Problèmes identifiés :
•	Jeûne prolongé journée
•	Hyperphagie nocturne
•	Stockage graisse nocturne accru
•	Glycémie instable
Adaptations comportementales :
Réorganisation répartition calories :
•	Petit-déjeuner : 30% calories journée
•	Déjeuner : 35% calories journée
•	Dîner : 25% calories journée
•	Collations : 10% calories journée
Solutions pratiques travailleur :
Préparer la veille :
•	Repas du midi en portions à emporter
•	Collations transportables
Petit-déjeuner copieux (6h30-7h) :
•	Complet et rassasiant pour tenir la matinée
•	Bouillie + œufs + pain complet + avocat + fruit
Déjeuner au travail (12h-13h) :
•	Apporté de la maison (contrôle qualité)
•	Riz complet + sauce + protéines + légumes
•	OU salade composée complète si pas de réchauffage
Collations travail :
•	10h : Fruits + arachides (sachet préparé)
•	16h : Gari + sardines OU fruits secs
Dîner tardif mais LÉGER (20h-21h) :
•	Soupe de légumes
•	Protéines grillées
•	PAS de féculents lourds
•	OU : Salade composée + poisson
Conseils repas tardif :
•	Manger 2-3h avant coucher minimum
•	Portions réduites
•	Pas de graisses lourdes
•	Marche digestive 15min après
Question 2 : Combien de portions de fruits et légumes consommez-vous par jour ?
RÉPONSE : 1-2 portions
Problème : Largement insuffisant (recommandation : 5 portions minimum)
Conséquences :
•	Carences vitamines A, C, K, folates
•	Fibres insuffisantes (constipation, glycémie instable)
•	Antioxydants faibles (inflammation)
•	Risque cardiovasculaire accru
Plan d'augmentation progressive :
SEMAINE 1-2 : Objectif 3 portions
•	Petit-déjeuner : 1 fruit (orange, papaye)

SECTION E : COMPORTEMENTS ALIMENTAIRES
Question 1 : Mangez-vous souvent par stress ou ennui ?
RÉPONSE : OUI
Problème : Alimentation émotionnelle 
Mécanisme :
•	Stress → Cortisol élevé → Fringales sucrées/grasses
•	Ennui → Distraction par nourriture
•	Réconfort temporaire → Culpabilité → Cercle vicieux
•	Calories excédentaires non contrôlées
•	Choix aliments malsains généralement
Identification triggers :
Journal émotionnel 2 semaines :
•	Noter chaque épisode alimentation émotionnelle
•	Heure
•	Émotion ressentie (stress, ennui, tristesse, colère, solitude)
•	Aliments consommés
•	Quantité
•	Satisfaction après
•	→ Identifier patterns
Stratégies gestion alternatives :
1. Techniques anti-stress immédiates :
•	Respiration 4-7-8 : Inspire 4s, retiens 7s, expire 8s (×3)
•	Marche 10min extérieur
•	Appel ami supportant
•	Écriture émotions (journal)
•	Musique apaisante
•	Prière/méditation
2. Activités distraction ennui :
•	Marche
•	Hobby manuel (tricot, dessin, bricolage)
•	Jardinage
•	Lecture
•	Jeux société famille
•	Rangement/organisation
•	Apprentissage nouveau (langue, instrument)
3. Alimentation consciente (si faim réelle) :
•	Pause avant manger : "Ai-je VRAIMENT faim ?"
•	Échelle faim 1-10 : Si <5, pas alimentation nécessaire
•	Attendre 10min : Besoin passe souvent
•	Si vraie faim : Collation saine planifiée
4. Environnement favorable :
•	Éliminer aliments réconfort de la maison
•	Stock collations saines uniquement
•	Cuisine fermée certaines heures
•	Zones "non-food" : Chambre, bureau
5. Support social :
•	Groupe entraide (diabète, perte poids)
•	Thérapeute/psychologue si sévère
•	Famille informée : Support
Remplacements alimentaires si échec retenue :
Au lieu de :
•	Beignets → Fruits + quelques arachides
•	Gâteaux → Carré chocolat noir (70%+) 2-3 carrés
•	Chips → Crudités + houmous/guacamole
•	Sodas → Eau citronnée, infusion
Plan progressif :
Semaine 1-2 : Conscience
•	Journal sans jugement
•	Identifier triggers
•	Pas de changement, juste observation
Semaine 3-4 : Substitution 50%
•	Remplacer 1 épisode/2 par alternative
•	Techniques respiration
•	Activité distraction
Semaine 5-6 : Substitution 75%
•	Majorité épisodes gérés sans nourriture
•	Habitudes alternatives ancrées
Semaine 7+ : Contrôle
•	Alimentation émotionnelle rare (< 1x/semaine)
•	Gestion triggers efficace
Adaptations repas structure :
•	Régularité stricte (évite fringales déclencheuses)
•	Protéines suffisantes (satiété longue)
•	Sommeil optimisé (fatigue = stress = fringales)
RÉPONSE : NON
Évaluation : EXCELLENT contrôle émotionnel-alimentaire
Maintien :
•	Continuer séparation émotions-alimentation
•	Vigilance périodes stress accru
•	Maintien stratégies coping non-alimentaires
Bénéfices :
•	Contrôle calorique facilité
•	Choix alimentaires rationnels
•	Perte poids moins chaotique
•	Relation saine nourriture
Question 2 : Avez-vous tendance à finir votre assiette même si vous n'avez plus faim ?
RÉPONSE : OUI
Problème : Ignorance signaux satiété → Suralimentation chronique
Causes culturelles/familiales fréquentes :
•	"Ne pas gaspiller"
•	Éducation "assiette vide"
•	Politesse sociale
•	Déconnexion signaux internes
Conséquences :
•	Calories excédentaires quotidiennes (200-500 cal)
•	Prise poids progressive
•	Estomac distendu (satiété retardée)
•	Inconfort digestif
Stratégies réapprentissage satiété :
1. Échelle faim-satiété (1-10) :
•	1-2 : Affamé, faiblesse
•	3-4 : Faim confortable
•	5-6 : Neutre, ni faim ni satiété
•	7-8 : Satisfait, confortablement repu
•	9-10 : Trop plein, inconfortable
Objectif repas :
•	Commencer repas à 3-4
•	Arrêter à 7 (pas 9-10)
2. Techniques ralentissement :
•	Mastiquer 20-30x chaque bouchée
•	Poser couverts entre bouchées
•	Pauses mid-repas (2-3min)
•	Conversation (si repas social)
•	Durée repas : Minimum 20min (satiété arrive)
3. Portions contrôlées :
•	Se servir moins initialement
•	"Petit assiette, grande assiette" illusion
•	Possibilité resservir SI faim (rarement besoin)
4. Restes acceptés :
•	Garder pour collation ultérieure
•	Partager famille
•	Congeler portions individuelles
•	Réframing : "Économiser pour demain" = pas gaspillage
5. Conscience corporelle :
•	Check-in mi-repas : "Ai-je encore faim ?"
•	Écoute signaux : Ralentissement mastication, soupir, perte intérêt nourriture
•	Respecter corps plutôt que obligations externes
6. Planification portions :
•	Calculer portions macro selon niveau activité
•	Peser/mesurer initialement (apprentissage)
•	Assiette modèle : ½ légumes, ¼ protéines, ¼ féculent
Adaptation culturelle :
Si repas famille/social :
•	Communiquer : "Je suis à l'écoute de mon corps"
•	Servir soi-même (contrôle portion)
•	Complimenter cuisinier (pas obligation finir)
•	Focus qualité pas quantité : "C'était délicieux, je suis satisfait"
Plan progressif :
Semaine 1-2 : Conscience
•	Noter échelle faim-satiété chaque repas
•	Pas changement, juste observation
•	Identifier pattern (toujours 9-10 fin repas?)
Semaine 3-4 : Ralentissement
•	Techniques mastication
•	Durée repas augmentée
•	Objectif : Arrêter 8
Semaine 5-6 : Portions
•	Réduire portions 20%
•	Objectif : Arrêter 7-8
Semaine 7+ : Maîtrise
•	Écoute corps naturelle
•	Arrêt 7 systématique
•	Restes sans culpabilité
Bénéfices attendus :
•	Réduction calorique 200-400 cal/jour
•	Perte poids 0.5-1kg/mois (juste par cet ajustement)
•	Digestion améliorée
•	Reconnexion corps
RÉPONSE : NON
Évaluation : EXCELLENT - Écoute signaux internes
Maintien :
•	Continuer respect satiété
•	Vigilance contextes spéciaux (buffets, fêtes)
Bénéfices :
•	Contrôle calorique naturel
•	Digestion optimale
•	Relation intuitive nourriture
•	Modèle enfants/famille

Question 4 : Si oui, lequel, et a-t-il été efficace pour vous ? Pourquoi ?
EXEMPLE RÉPONSE 1 : "Régime très faible en glucides, j'ai perdu du poids rapidement mais tout repris après"
Analyse échec :
•	Effet yoyo classique

•	Métabolisme ralenti
•	Reprise poids + rebond (souvent plus qu'initial)

Leçons et nouvelle approche :
1. Modération vs Élimination :

•	Pas privation sévère
•	Flexibilité sociale
3. Éducation :
•	Comprendre POURQUOI manger quoi

•	Lipides : 28-38% selon activité

EXEMPLE RÉPONSE 2 : "Régime liquide/detox, j'ai été fatigué et j'ai arrêté rapidement"

•	Fatigue → Abandon

2. Équilibre nutritionnel
•	Tous macronutriments nécessaires
•	Tous micronutriments
•	Variété alimentaire
3. Énergie suffisante
•	Pas déficit extrême (<1200 cal femme, <1500 cal homme)
•	Énergie pour vivre, travailler, bouger
Nouvelle approche :
Alimentation solide équilibrée :
•	3 repas complets quotidiens
•	2 collations
•	Variété aliments entiers
•	Protéines chaque repas
•	Légumes abondants
•	Féculents contrôlés qualité

•	Bouillie maïs - 200g

•	Fruit

•	Riz complet
•	Sauce feuilles

•	Légumes
•	VS bouillon/soupe minceur
Dîner SOLIDE :
•	Fonio
•	Légumes vapeur
•	Protéines
•	VS shake protéiné
Bénéfices alimentation solide :
•	Satiété durable
•	Énergie stable
•	Préservation muscle
•	Nutriments complets
•	Soutenable long terme
